## 💨 Основные функции

### 1. **Автоматический мониторинг форума**
1. Отслеживание новых тем в заданном разделе
2. Периодическая проверка обновлений

### 2. **Генерация ответов с использованием ИИ**
1. Использование модели GPT-4 mini для создания контекстуальных ответов
2. Обработка упоминаний пользователя

### 3. **Имитация человеческого поведения**
1. Добавление случайных опечаток
2. Расширение словарного запаса с помощью синонимов
3. Использование разговорных частиц и сленга
4. Случайное добавление эмодзи

### 4. **Управление активностью**
1. Планово поднятие определенных тем ("бамп")
2. Настраиваемые интервалы между действиями

### 5. **Режим сна**
1. Приостановка активности в заданные часы

## Обновления сервиса

1. **Обновлён API g4f**
   Интеграция переписана на новый клиентский API `g4f.client.Client`.

2. **Обновлена зависимость g4f**
   Версия `g4f` в `requirements.txt` обновлена до `g4f==7.5.6`.

3. **Защита от prompt injection**
   Текст с форума теперь передаётся как JSON-объект `forum_message` с явным правилом, что это недоверенный контент. Это снижает риск, что пользовательский текст сможет повлиять на системные инструкции ИИ.

4. **Секреты вынесены в окружение**
   `LZT_TOKEN` и настройки бота теперь читаются из переменных окружения или файла `.env`, а не хранятся прямо в коде.

5. **Добавлен пример `.env`**
   Добавлен файл `.env.example`, чтобы было проще и безопаснее настраивать бота перед запуском.

6. **Таймауты для запросов**
   Все `GET` и `POST` запросы теперь проходят через `request_with_timeout`. Это защищает бота от зависания при медленном или сломанном соединении.

7. **Настраиваемое упоминание бота**
   Упоминание бота больше не захардкожено на `hove`. Теперь его можно нормально настроить.

8. **Безопасная обработка тем**
   Прямое обращение к полям темы заменено на безопасные `.get()`. Это помогает избежать падений из-за `KeyError`, если в ответе форума нет нужного поля.

9. **Исправлена утечка thread tracking**
   Утечка в `threads_ready` исправлена через ограниченную очередь `deque` и `set`. Теперь список обработанных тем не растёт бесконечно.

10. **Исправлен ночной режим**
    Ночной режим теперь корректно работает, даже если его период проходит через полночь.

11. **Исправлена вставка разговорных частиц**
    Исправлено смещение индексов в `add_conversational_particles`. Теперь добавление разговорных слов не ломает позиции в тексте.
    
## Технические особенности

- Использование API форума для взаимодействия
- Обработка ошибок и повторные попытки при сбоях
- Подробное логирование всех действий
- Настраиваемые параметры работы (задержки, вероятности, интервалы)

## Используемые библиотеки

- `requests`: для HTTP-запросов
- `g4f`: для работы с GPT
- `loguru`: для удобного логирования

Данный скрипт представляет собой сложную систему автоматизации, имитирующую поведение реального пользователя форума. Его следует ***использовать с осторожностью*** и в соответствии с правилами форума. **Главное, не злоупотребляйте этим скриптом!**
